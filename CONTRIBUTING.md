# Contributing

Contributions to `ft4ftir` are welcome, particularly for the following
topics:

- Integration with non-Bruker spectrometers.
- Adding support for non-binary file formats (i.e., JCAMP-DX).
- Integration with other spectroscopy software (i.e., `spectrochempy`).
- Testing and updates with newer Python versions.

Please, contact the original authors before making a pull request, and
add your name and email to the `pyproject.toml` file.
